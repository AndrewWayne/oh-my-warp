# omw-local-preview v0.0.13

This public Pre-release combines Mac and Windows downloads. It preserves
existing omw features while bringing the Mac maintenance work and selected
0.0.12 improvements together under version 0.0.13.

## Platform Sources

- **Mac:** complete 0.0.11 baseline, macOS 27 maintenance repairs, and four
  selected 0.0.12 improvements. The accepted local 0.0.13 app is retained.
- **Windows:** 0.0.12 application behavior, rebuilt with the 0.0.13 version.
  Windows application features are unchanged. Packaging adds failure-stage
  diagnostics and retains the existing integrity and installer gates.

The platform sources are intentionally recorded separately. This trial does
not replace omw's custom code with a new upstream tree. The attached
platform manifest identifies corresponding source commits and asset hashes.

## Mac Repairs And Additions

- Repair native close, minimize, fullscreen, Option-green zoom and resize handling
  on macOS 27 while preserving terminal/tab/pane dragging.
- Support Codex local file paths with line/column ranges, OSC 8 file URLs and
  anchored Markdown source jumps, including correct editor columns.
- Correct notification hook detection, custom `CODEX_HOME`, command quoting,
  dispatcher execution, permission feedback and notification-click completion.
- Redact API keys and token-bearing pairing links from new process logs.
- Add provider connection tests using the current settings form without saving.
  This tests `GET /models` connectivity/authentication, not model inference.
- Support local Ollama without an API key or an Authorization header.
- Keep phone sharing available in each local pane, including alternate-screen
  programs, with per-pane stop/close cleanup. Default pairing remains read-only;
  the Mac attachment repair allows output while rejecting input and remote resize.

Existing local Agent, providers, notifications, OSC 8 links, wrapped paths,
tabs/panes and update controls remain part of the Mac baseline. Windows retains
the native terminal, Credential Manager, local-provider and pane-sharing work
from 0.0.12.

## Downloads

- Mac Apple Silicon: `omw-warp-oss-v0.0.13-aarch64-apple-darwin.dmg` and `.sha256`.
- Windows x64 portable: `omw-warp-oss-v0.0.13-x86_64-pc-windows-msvc.zip` and `.sha256`.
- Windows x64 installer: `omw-warp-oss-v0.0.13-x86_64-pc-windows-msvc-setup.exe` and `.sha256`.

Separate Mac and Windows source archives and `omw-v0.0.13-platform-manifest.json`
identify the source commits, build evidence, asset sizes and SHA-256 hashes.
GitHub's automatic Source code archive points to the Mac release tree;
use the attached Windows source archive for the Windows packages.
Source archives retain `.gitmodules`; the platform manifest lists the pinned
submodule commits because `git archive` does not include submodule contents.

Mac installation: open the DMG and drag `omw-warp-oss.app` to Applications.
Windows installation: run the setup EXE for a per-user installation, or extract
the entire portable ZIP before starting `omw-warp-oss.exe`. Keep the bundled
Node, Agent, helper, DLLs and other files with the executable. These downloads
do not replace the running application automatically.

The Mac preview is not notarized. If macOS quarantines the downloaded app,
the existing preview-track installation command is:

```sh
xattr -d com.apple.quarantine /Applications/omw-warp-oss.app
```

## Verification And Limits

The Mac package passed version/signature/integrity/source-byte/provenance checks,
bundled Agent streaming/approval/cancellation/error tests and the notification
installation/detection/dispatch lifecycle. Supporting suites passed: Agent
95 tests, app integration 103 tests, remote protocol 103 tests; existing
skips/ignores are documented in the source reports.

The full Windows build passed on a real Windows runner: ZIP path/file/hash
validation, the forbidden-cloud audit, bundled Node/Agent and Credential Manager
helper probes with a developer-free PATH, then first install, locked-upgrade
protection, replacement upgrade, payload/shortcut/registration checks and uninstall.
Build and acceptance: [GitHub Actions run 37606388621](https://github.com/AndrewWayne/oh-my-warp/actions/runs/37606388621).
These checks do not cover manual Windows desktop workflows or execution on older
Windows versions.

Final foreground settings restart/readback and two-pane browser sharing/close
cleanup checks remain pending after the host locked. Physical phone/Tailscale,
real model-provider credentials, older macOS and installed-app update swapping
were not accepted in the Mac maintenance work. These limits remain open.

Mac retains minimum macOS 11.0 metadata and is Apple-Silicon-only; older-system
execution is unverified. Its ad-hoc signature is not Apple notarization.
Windows requires Windows 10 or newer and remains x64-only. Production signing
and Linux packaging are deferred.

This is a publicly downloadable **Pre-release**, not a stable release.
The latest stable release remains 0.0.11.
