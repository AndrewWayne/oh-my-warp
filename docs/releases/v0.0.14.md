# oh my warp 0.0.14 (Pre-release)

本次试用版保留原有功能，重点修复 Mac 上 Codex 输出文件路径的点击跳转。
Mac 保留 0.0.11 自定义功能、0.0.13 的 macOS 27 维护修复和四项功能改进；
Windows 保持 0.0.13 的应用行为，仅按新版本标识重新构建。

## 本次更新

- Codex 开启鼠标支持后，文件路径仍能识别和点击。
- 中文文件名和 `.md` 后缀完整高亮；窄窗口换行、空格和连续路径列表正确识别。
- 支持相对路径、`./`、`../`，按对应 Codex 会话目录解析。
- 兼容 `-C` / `--cd` 指定目录及已验证的 worktree 场景，保留行列定位和 OSC 8 链接。

通知、模型连接检测、无密钥 Ollama、手机共享、日志脱敏、标签页和分屏等现有
功能继续保留。本次没有整体替换上游代码，也没有修改 Codex 提示词。

## 下载

- Mac Apple Silicon：`omw-warp-oss-v0.0.14-aarch64-apple-darwin.dmg`
- Windows x64 便携包：`omw-warp-oss-v0.0.14-x86_64-pc-windows-msvc.zip`
- Windows x64 安装程序：`omw-warp-oss-v0.0.14-x86_64-pc-windows-msvc-setup.exe`

每个安装包附带 SHA-256 校验文件。平台清单和独立源码归档记录对应的源码版本、
构建证据及校验值。GitHub 自动生成的 Source code 指向 Mac 源码；Windows
请使用独立的 Windows 源码归档。源码归档保留 `.gitmodules`，子模块固定版本
列在平台清单中；归档不包含子模块内容。

Mac：打开 DMG，将 `omw-warp-oss.app` 拖入 Applications。
Windows：运行安装程序，或完整解压便携包后启动 `omw-warp-oss.exe`。
请保留随包提供的 Node、Agent、辅助程序和 DLL。下载不会自动替换正在运行的应用。

Mac 包采用 ad-hoc 签名，尚未经过 Apple 公证。如下载后受隔离属性阻止，可使用：

```sh
xattr -d com.apple.quarantine /Applications/omw-warp-oss.app
```

## 验证与边界

路径修复已通过回归测试、真实 Codex 输出回放，以及用户协助的 root/worktree
鼠标验收。发布产物的最终检查结果及 Windows runner 记录见随包平台清单。

无法确定 Codex 会话目录时，相对路径会跳过识别，避免打开错误副本。
共享 daemon 模式未指定 `-C` 的相对路径仍属未验证范围；路径重建最多八行、
8192 字节。更旧 Codex 数据库格式及 TUI 内切换目录没有穷尽验证。
Codex 输入编辑保留当前行为，本版未加入 Command+Delete 或真正的撤销/重做。

Mac 保留最低 macOS 11.0 标识，但只完成 macOS 27 上的本地验收，旧系统运行未验证。
Windows 要求 Windows 10 或更新版本；桌面手工交互和旧 Windows 版本未完成验收。
真实模型服务凭据、实体手机/Tailscale、最终设置重启读回及前台双分屏共享清理
仍保留原验收边界。Mac Intel、Linux 安装包和正式签名暂不提供。

这是公开可下载的 **Pre-release（试用版）**。0.0.13 下载继续保留，最新正式版仍为 0.0.11。
