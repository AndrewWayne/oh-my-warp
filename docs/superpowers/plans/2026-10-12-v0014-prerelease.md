custom features remain intact.

PTY process context, and the existing file opener cooperate to resolve Codex
references. Windows retains its separate 0.0.12-derived source and packaging.

**Technical contract:** Commit the accepted Mac source/tests and diagnosis

source, dependencies, and build scripts must match its 0.0.13 baseline. Exclude

diffs, pass header and secret checks, and verify pushed commit SHAs. Record

**Technical contract:** Version 0.0.14; Mac arm64, Windows x64. Use Rust 1.92.0

**Dependencies:** Published source and a draft release pointing to Mac source.

**Semantic acceptance:** Rerun focused file-link regressions and replay captured
